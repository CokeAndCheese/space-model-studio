## 1. 文档目的

本文定义 Space Model Studio 的统一交互语言，覆盖项目树、2D/3D 视口、选择、绘制、属性编辑、上下文菜单、撤销恢复、状态反馈和无障碍要求。

本规范解决以下核心问题：

- 同一动作在项目树、2D、3D 和属性面板中具有一致结果。
- 选择、绘制和相机导航互不抢占。
- 所有创建与编辑动作都有可见过程、明确提交点和可恢复路径。
- 模型状态、选择状态和相机状态相互独立，任何选择操作都不得导致模型消失。
- 产品行为可以被自动化测试和人工验收准确判断。

本文中的术语：

- **必须**：发布 v1.0 前必须满足。
- **应该**：原则上应满足；偏离时必须记录原因。
- **可以**：增强能力，不作为 v1.0 发布阻断项。

## 2. 设计依据

本规范采用“BIM 导航 + CAD 选择 + Web 可访问性”的组合基线：

- [ISO 9241-110:2020](https://www.iso.org/standard/75258.html)：任务适配、可理解、符合预期、可控制和错误可恢复等通用交互原则。
- [Autodesk Revit 导航](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-GetStarted/files/GUID-1A152ED7-5636-4160-B7D4-5A54A29AB3CE.htm)：滚轮缩放、中键平移、Shift+中键旋转和 ViewCube 标准视图。
- [AutoCAD 选择规则](https://help.autodesk.com/cloudhelp/ENU/AutoCAD-Web-Help/files/Drafting-and-Creating/AutoCAD_Web_Help_Drafting_and_Creating_SELECT_html.html)：左到右完全包含、右到左相交即选。
- [Revit 元素选择](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-GetStarted/files/GUID-71F54593-506C-4068-89BC-3385D5576F02.htm)：悬停预高亮、Tab 候选循环、跨视图同步选择。
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：键盘可操作、指针取消、拖拽替代方案和最小点击目标。

## 3. 总体交互原则

### 3.1 状态可见

系统必须持续显示：

- 当前工具。
- 当前楼层和视图模式。
- 当前选择数量。
- 当前指针坐标、网格步长和吸附状态。
- 绘制中的长度、角度、约束和候选吸附点。
- 保存、验证和导出的进行中、成功或失败状态。

仅依靠光标形状表达关键状态是不合格的；工具栏激活态、视口提示和状态栏至少要有两处反馈。

### 3.2 操作可预测

- 相同手势在不同工具中不得产生相反结果。
- 左键负责选择、放置和确认，不负责常规相机旋转。
- 中键和滚轮专用于视图导航，绘制工具激活时仍应可用。
- 右键负责上下文菜单；短按右键不得旋转视图。
- 删除、导入覆盖和级联删除必须明确说明影响范围。

### 3.3 操作可取消、可恢复

- 正在绘制的临时几何必须可以用 Esc 取消。
- 已提交的模型修改必须进入 Undo/Redo 历史。
- 单次撤销必须对应用户可以理解的一次提交。
- 取消预览不得删除已经提交的对象。
- 选择、框选和相机导航不得产生项目脏状态。

### 3.4 状态相互独立

必须分别维护：

1. Domain 模型状态。
2. 当前工具与命令状态。
3. 选择集合。
4. 项目树焦点节点。
5. 相机位置、方向、缩放和目标点。
6. 临时预览几何。

选择高亮必须原位更新材质或辅助轮廓，不得为了改变高亮而销毁、重建全部正式模型。

## 4. 页面区域与焦点

界面采用四个主要工作区：

```text
顶部：项目命令、工具栏、当前工具
左侧：项目 / 单体 / 楼层 / 构件树
中部：2D / 3D 视口与 Issues
右侧：当前树节点或构件的属性面板
底部：坐标、单位、验证和选择状态
```

焦点规则：

- 点击视口后，键盘快捷键作用于视口和当前工具。
- 点击文本输入框后，字符键优先输入文本；Delete、Space、F 等视口快捷键不得误触发。
- Esc 优先关闭最内层状态：下拉菜单 → 上下文菜单 → 当前预览 → 当前工具。
- 切换楼层或项目时，未提交的临时预览必须先取消。

### 5.1 鼠标与触控板

| 左键单击 | 选择、放置点、确认 | 选择、放置点、确认 |

## 6. 相机与视口导航

### 6.1 2D 模式

- 必须使用正交相机和 XZ 工作平面。
- 相机保持俯视方向，不允许因普通左键拖动产生倾斜。
- 滚轮缩放后，指针下方的模型位置应尽量保持不动。
- 当前楼层正常显示；其他楼层默认隐藏，后续可以支持半透明参照。

### 6.2 3D 模式

- 必须使用透视相机。
- Shift+中键围绕明确的 pivot 旋转。
- 有选中构件时，旋转 pivot 应优先使用选择包围盒中心；否则使用当前楼层包围盒中心。
- 必须提供顶、前、后、左、右和等轴测标准视图入口。

### 6.3 适配视图

- “适配选择”使用全部选中对象的世界包围盒。
- “适配楼层”使用当前楼层全部可见对象的世界包围盒。
- 空场景执行适配时不得产生 NaN、极端缩放或相机跳转。
- 导入偏离原点的 GLB 后必须自动执行一次适配视图。
- 切换 2D/3D 时应保留当前工作中心；若模型完全在视锥外，自动回退到适配楼层。

### 6.4 相机稳定性

以下操作不得改变相机：

- 单击或框选。
- 修改选择高亮。
- 项目树选中同一楼层中的节点。
- 打开或关闭构件上下文菜单。
- 修改不影响模型包围盒的 metadata。

## 7. 选择系统

### 7.1 单击选择

- 普通单击构件：以该构件替换选择集合。
- Ctrl/Cmd+单击：将构件加入或切换出选择集合。
- Shift+单击：从选择集合移除构件。
- 单击空白：清空构件选择；项目树焦点回到当前楼层。
- 选中结果必须同步到项目树、视口轮廓、属性面板和状态栏。

### 7.2 框选

框选必须允许从空白处或模型表面开始：

- 左→右为 **Window Selection**：只有投影包围盒完全处于选择框内的构件才选中。
- 右→左为 **Crossing Selection**：投影包围盒与选择框相交即选中。
- Window 使用青绿色半透明填充和实线边界。
- Crossing 使用橙色半透明填充和虚线边界。
- 线型是强制区分手段，不能只靠颜色。
- 框选期间必须暂停相机控制；完成后恢复原相机位置、方向、缩放和目标点。

v1.0 默认采用“穿透选择”：只要构件处于当前视锥且符合屏幕投影规则，即使被其他构件遮挡也可入选。后续可以增加“仅选择可见表面”模式，但必须在 UI 中明确标识。

### 7.3 选择过滤

- `visible=false` 的构件不得通过视口选中，但必须保留在项目树中。
- 锁定构件可以通过树或单击进行只读检查，但默认不进入批量框选。
- 锁定构件不得被移动、修改或删除。
- renderType 过滤器只影响可见候选，不得删除或修改模型数据。
- v1.0 的构件多选限制在当前楼层；跨楼层多选不在范围内。

### 7.4 悬停与重叠候选

- 指针靠近可选构件时应显示预高亮，不改变正式选择。
- 状态栏显示候选名称、renderType 和 SID。
- 多个构件重叠时，Tab/Shift+Tab 循环候选。
- 预高亮和已选高亮必须有明显差异。

## 8. 项目树

### 8.1 可选择层级

以下四级节点全部必须可选择：

```text
Project
└── Building
    └── Floor
        └── Entity
```

选择行为：

| 节点 | 左侧高亮 | 构件选择集合 | 视口 | 右侧属性 |
| --- | --- | --- | --- | --- |
| Project | 项目根 | 清空 | 保持当前楼层 | 项目标识与统计 |
| Building | 当前单体 | 清空 | 切换至该单体有效楼层 | 单体标识与统计 |
| Floor | 当前楼层 | 清空 | 切换并适配该楼层 | 楼层标识与参数 |
| Entity | 当前构件 | 更新 | 高亮构件 | 构件属性与 metadata |

### 8.2 树与视口同步

- 视口选中构件后，项目树必须定位并高亮对应节点。
- 框选多个构件时，树中所有已选构件均显示多选态，第一个构件作为属性面板主对象。
- 树中选择构件后，视口不得自动改变相机；仅在构件完全不在视锥内时提供“定位”按钮，不自动跳转。
- 当前工作楼层和树焦点是两个概念，必须使用不同视觉状态。

### 8.3 树节点辅助操作

- 仅构件节点显示显示/隐藏和锁定入口。
- 右键前必须先将该节点设为当前焦点。
- 搜索命中应展开祖先节点并高亮匹配文本。
- 搜索或过滤不得丢失已经选择但暂时不可见的模型状态；应提示“选择中有 N 个对象被过滤”。

## 9. 工具与命令状态机

所有创建工具必须遵循统一状态机：

```text
IDLE
  → READY（工具已激活）
  → ANCHORED（已确定首点或宿主）
  → PREVIEWING（动态预览）
  → COMMITTED（一次有效提交）
  → READY（工具保持激活）
```

取消路径：

```text
PREVIEWING --Esc--> READY
READY --Esc--> IDLE / 选择工具
```

通用要求：

- 工具按钮必须持续显示激活态。
- 完成一次创建后，除一次性命令外不得自动切换到选择工具。
- 临时预览必须使用独立对象组，不写入 Domain，不进入导出。
- 提交前必须验证最小尺寸、宿主、重叠和几何合法性。
- 提交成功后才写入 Domain，并作为一次 Undo 事务。
- 提交失败时保留当前工具和可修正的输入上下文。

## 10. 墙体绘制

### 10.1 基本流程

1. 激活墙体工具，状态进入 READY。
2. 第一次左键确定起点，显示起点标记。
3. 指针移动时显示半透明实体墙、中心线、终点标记、长度、角度和吸附状态。
4. 第二次左键提交墙体。
5. 墙体工具保持激活，等待下一段起点。

### 10.2 实时预览

- 预览墙高度使用当前楼层默认墙高，厚度使用当前墙工具参数。
- 预览与最终提交必须调用同一个端点解析函数。
- 自由角度、自动近轴正交和 Shift 强制正交的结果必须在预览中立即可见。
- 长度显示精度为 0.01 m；底层坐标保留项目精度，不得用显示值反算。
- 无有效终点时仅显示起点，不显示零长度墙体。

### 10.3 连续绘制

- v1.0 默认“工具持续、分段独立”：完成一段后仍是墙体工具，但下一次点击开始新墙。
- 可以提供“连续墙链”开关；启用后上一段终点自动成为下一段起点。
- Enter 或双击结束连续墙链，但不强制退出墙体工具。
- 每一段墙作为独立 Undo 事务，撤销一次只删除最后提交的一段。

### 10.4 取消与异常

- 已定起点时按 Esc：取消当前预览，保留墙体工具。
- READY 状态按 Esc：退出墙体工具并回到选择工具。
- 长度小于或等于 0.1 m：不创建，并提示“墙体长度不足”。
- 切换楼层、打开项目或切换工具：必须清理临时预览。

## 11. 门窗及其他构件放置

### 11.1 门窗

- 悬停墙体时显示宿主预高亮和沿墙偏移。
- 预览必须显示门窗宽高、开启方向或窗台高度。
- 无有效宿主、超出墙长或与既有洞口重叠时，使用红色无效预览并禁止提交。
- 创建成功后宿主墙与 opening 引用必须在同一 Undo 事务中更新。

### 11.2 楼板、天花和空间

- 多边形绘制时持续显示闭合预览、边长和最后一条待确认边。
- Enter、双击首点或点击“完成”结束多边形。
- Esc 先撤销当前未提交点，再次 Esc 取消整个临时多边形。
- 自相交、面积过小或点数不足时禁止提交并标明问题边。

### 11.3 设施、楼梯和电梯

- 放置前显示占地范围和朝向。
- 旋转应有可见角度反馈和正交吸附。
- 设施安装高度、楼梯方向和电梯中心必须在提交前可确认。

## 12. 吸附与精确输入

### 12.1 默认吸附优先级

同一距离内存在多个候选时，默认优先级为：

1. 已有构件端点。
2. 交点和宿主中心线。
3. 中点、垂足和延长线。
4. 平行/正交约束。
5. 网格。
6. 自由坐标。

Tab 可以循环同一区域的候选；Alt/Option 临时关闭吸附。

### 12.2 视觉反馈

- 不同吸附类型使用不同图形标识，不能只用颜色。
- 状态栏显示吸附类型和精确坐标。
- 吸附半径以屏幕像素计算，不得因相机缩放而在屏幕上明显改变。
- 吸附到端点时应复制精确坐标，不得再次经过网格四舍五入。

### 12.3 数值输入

- 绘制首点后直接输入数字，可锁定长度。
- 输入 `长度,角度` 可以精确确定终点；格式由本地化层解析。
- 无效数值不得提交，并保留原输入供修正。

## 13. 属性面板

- 属性面板根据树节点类型渲染独立 schema，不得把 Project/Building/Floor 强制转换为 Entity。
- 多选构件时，只显示共有字段；值不一致时显示“多值”。
- 输入框失焦或 Enter 时提交，Esc 恢复编辑前值。
- 单字段编辑为一个 Undo 事务；连续键入不得每个字符产生一条历史记录。
- 只读 ID、自动 SID 和派生字段必须有清晰只读样式。
- 校验错误紧邻字段显示，并同步到 Issues 面板。

## 14. 显示、锁定与删除

### 14.1 显示与锁定

- 隐藏只影响渲染和视口选择，不删除数据。
- 锁定只阻止修改和删除，不阻止通过项目树检查属性。
- 隐藏或锁定状态必须在树和属性面板同步。
- 对多个对象批量操作时，应显示影响数量。

### 14.2 上下文菜单

- 右键构件时先选择该构件，再打开菜单。
- 菜单靠近指针，并限制在可视窗口内。
- 单击空白、Esc、滚动、窗口 resize 或操作完成后关闭。
- 不可用命令必须禁用并解释原因，不能点击后无反馈。

### 14.3 删除

- Delete 和右键删除必须复用同一 Domain 命令。
- 锁定构件不得删除。
- 删除墙体时必须计算宿主门窗影响；存在级联对象时显示影响数量并要求明确确认。
- 墙及其级联洞口作为一个 Undo 事务。
- 删除成功后选择集合移除已删除 ID，树焦点回到当前楼层或下一可用对象。

## 15. Undo / Redo

以下动作必须进入历史：

- 创建、删除、复制或移动构件。
- 修改尺寸、位置、metadata、名称、可见性或锁定状态。
- 新增、复制或删除楼层。
- 级联宿主关系修改。

以下动作不得进入历史：

- 选择、框选和悬停。
- 相机平移、旋转、缩放和适配。
- 搜索、过滤、切换 Issues 标签。
- 打开或关闭菜单。

Undo/Redo 后必须校正当前楼层、选择集合和树焦点，禁止保留指向已不存在对象的 ID。

## 16. 2D / 3D 与楼层切换

- 2D 和 3D 使用同一 Domain 和选择集合。
- 切换视图模式前取消当前临时绘制，不影响已提交构件。
- 切换模式后保持当前楼层和选择。
- 切换楼层时清空当前楼层构件选择，并把树焦点设为目标楼层。
- 目标楼层有模型时自动适配；空楼层使用稳定的默认相机。
- 楼层切换不得修改模型可见性字段；跨楼层显示由视图策略控制。

## 17. 导入 GLB 的交互要求

必须明确区分两种行为：

1. **检查 GLB**：只解析和验证文件，不加入视口。
2. **导入到场景**：加载模型、显示层级并进入兼容编辑模式。

界面文案不得把“检查成功”写成“导入成功”。导入到场景时：

- 显示解析进度和错误。
- 保留原始 mesh 层级和 metadata。
- 完成后自动适配模型世界包围盒，包括远离原点的模型。
- 普通 GLB 必须明确提示“可编辑语义，但不保证恢复参数化墙体与宿主关系”。
- 导入失败不得清空现有项目或当前视口。

## 18. 状态反馈与错误处理

### 18.1 反馈层级

- **视口内提示**：当前手势、吸附、长度和无效预览。
- **Toast**：短暂成功、警告和非阻断错误。
- **字段错误**：属性输入的具体问题。
- **Issues 面板**：可定位、可持续检查的项目问题。
- **阻断对话框**：不可逆或高影响操作。

### 18.2 消息要求

消息必须包含“发生了什么”和“用户下一步能做什么”，例如：

- 合格：`墙体长度不足，请移动终点至 0.1 m 以外。`
- 不合格：`创建失败。`

不得只在控制台记录用户可操作的错误。

## 19. 可访问性

- 所有工具栏、树节点、菜单和属性字段必须可通过键盘到达。
- 可操作目标至少满足 24 × 24 CSS px，推荐 32 × 32 CSS px。
- 键盘焦点必须清晰可见。
- 框选应提供“两次单击确定两个角点”的非拖拽替代方式。
- 缩放必须同时提供按钮或菜单入口，不能只依赖滚轮或双指手势。
- 颜色不是唯一状态编码；选中、框选、错误和锁定还要使用线型、图标或文本。
- 指针按下不应立即执行删除等动作；提交应发生在 pointer-up、单击确认或可撤销命令中。
- 动画应尊重 `prefers-reduced-motion`。

## 20. 性能与稳定性门槛

- 选择高亮不得触发全场景几何重建。
- 指针移动期间不得写入 Vue/Domain 深层模型，仅更新临时预览。
- 预览对象必须复用 geometry/material，避免每帧创建和释放 GPU 资源。
- 大模型框选可以分帧处理，但选择框必须保持即时响应。
- 视口 resize、模式切换和框选结束后，相机矩阵必须保持有限数值。
- 模型加载或重建失败时保留上一稳定场景，并显示明确错误。

## 22. v1.0 范围外能力

以下能力可以后续单独设计，不应在 v1.0 中隐式实现：

- 跨楼层构件多选和批量编辑。
- 面、边、顶点级子对象编辑。
- 协同编辑、多人光标和冲突合并。
- 触屏专用多指手势体系。
- 普通三角网格自动恢复为参数化 BIM 构件。
- VR/AR 空间交互。

## 23. 变更管理

- 修改输入映射、选择语义、命令提交点或 Undo 粒度，必须升级规范版本并补充验收用例。
- 实现与本文不一致时，应在 Issues 或迁移说明中记录，不得静默形成第二套交互规则。
- 每次发布前，自动化测试与人工浏览器冒烟必须共同覆盖第 21 节相关条目。
